# my_Go_training

Those are some exercices to learn **Golang** programing language.\

## Bases/hello.go

First, I did an exercice to learn how to print.\
I had to print "Hello, 42!" on stdout.

Output :
```bash
Hello, 42!
```

## Bases/countdown.go

Then, I had to print on stdout numbers from 0 to 9.\
I decided to use `for` loop.

Output :
```bash
9876543210
```

## Bases/FizzBuzz.co

On this exercice, I had to manage an input.\
I received a number N on Stdin, an for each number until N, i had to write FizzBuzz if it was a multiple of 3 and 5, Fizz if it was a multiple of 3 and Buzz if it was a multiple of 5.\
In case the number was not a multiple of 5 neither 3, i had to display the number itself.

Example :\
Input :
```bash
5
```
Output :
```bash
1
2
Fizz
4
Buzz
```

## Bases/square.go

Here I had to receive a number on stdin, calculate it's square et display the result on the standard output.

Input :
```bash
4
```
Output :
```bash
16
```

## Bases/Even_or_odd.go

The purpose of this exercice was to receve a number on stdin, and display "impair" if the number was odd, or "pair" if the number was even.

Input :
```bash
7
```
Output :
```bash
impair
```
